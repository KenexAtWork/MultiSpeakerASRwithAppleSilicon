# Scripts

This directory contains maintenance and utility scripts.

## File Descriptions

- **cleanup_for_git.sh** - Git cleanup script
  - Used to clean test files and outputs
  - Use before committing to Git
  - Already executed, kept for reference

## Usage

```bash
# Clean test files
cd ~/Utils/asr
./scripts/cleanup_for_git.sh
```

**Note:** This script will delete all test videos, output files, and logs. Use with caution.
