# Screenshots 目錄

請將以下截圖放置在此目錄：

## 需要的截圖檔案

1. **01-main-interface.png** - 主界面截圖
   - 顯示檔案選擇區域
   - 顯示參數設定（模型、語言、格式）
   - 顯示 HF Token 輸入框
   - 對應你提供的第三張截圖

2. **02-transcription-result.png** - 轉錄結果截圖
   - 顯示處理日誌
   - 顯示轉錄結果（含 SPEAKER 標記）
   - 顯示字幕編輯器和音訊播放器
   - 對應你提供的第二張截圖

3. **03-aws-summary.png** - AWS Bedrock 摘要功能截圖
   - 顯示摘要生成界面
   - 顯示 Prompt 輸入框
   - 顯示模型和區域選擇
   - 顯示生成的摘要結果
   - 對應你提供的第一張截圖

## 如何添加截圖

```bash
# 將截圖複製到此目錄
cp /path/to/your/screenshot1.png screenshots/01-main-interface.png
cp /path/to/your/screenshot2.png screenshots/02-transcription-result.png
cp /path/to/your/screenshot3.png screenshots/03-aws-summary.png
```

## 截圖建議

- 解析度：建議 1920x1080 或更高
- 格式：PNG（保持清晰度）
- 內容：確保敏感資訊（如 Token）已遮蔽或使用測試資料
