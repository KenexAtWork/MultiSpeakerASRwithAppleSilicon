# Screenshots Directory

Please place the following screenshots in this directory:

## Required Screenshot Files

1. **01-main-interface.png** - Main interface screenshot
   - Shows file selection area
   - Shows parameter settings (model, language, format)
   - Shows HF Token input field
   - Corresponds to your third screenshot

2. **02-transcription-result.png** - Transcription result screenshot
   - Shows processing logs
   - Shows transcription results (with SPEAKER labels)
   - Shows subtitle editor and audio player
   - Corresponds to your second screenshot

3. **03-aws-summary.png** - AWS Bedrock summarization feature screenshot
   - Shows summary generation interface
   - Shows Prompt input field
   - Shows model and region selection
   - Shows generated summary results
   - Corresponds to your first screenshot

## How to Add Screenshots

```bash
# Copy screenshots to this directory
cp /path/to/your/screenshot1.png screenshots/01-main-interface.png
cp /path/to/your/screenshot2.png screenshots/02-transcription-result.png
cp /path/to/your/screenshot3.png screenshots/03-aws-summary.png
```

## Screenshot Recommendations

- Resolution: Recommend 1920x1080 or higher
- Format: PNG (maintains clarity)
- Content: Ensure sensitive information (like Tokens) is masked or use test data
